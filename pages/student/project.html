PYTHON / FINAL PROJECT

Build a Study Task Manager

Combine functions, lists and dictionaries in a program you can run and test.

Your project

Open project workspaceReview test results

The brief

Read a number of task records. Each record has a title and a status: done or todo. Store the tasks in a list of dictionaries and write count_done(tasks) to count completed records.

Print a summary in the form Completed: X/N. Your solution must also handle an empty task list.

Input:
2
Read,done
Code,todo

Output:
Completed: 1/2

The workspace includes starter code, detailed requirements and automated test cases. Start there, then use the test results to improve your solution.

After you pass

Extend your own version with commands to add, list and complete tasks. Keep the tested version as a baseline before adding features.
