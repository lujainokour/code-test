### 1. ملفات تشغيل أساسية خارج Git — أولوية عاجلة للتسليم

الملفات موجودة محلياً، ولذلك فحص وجود المراجع ناجح. لكن نسخة جديدة تعتمد فقط على الملفات المتتبعة في HEAD ستفتقد هذه الاعتماديات، مما يعطل ميزات أو صفحات. يلزم مراجعة ملفات المنتج وحفظها بصورة منظمة، ثم اختبار نسخة نظيفة. لا يُنصح بإضافة جميع التقارير والمخرجات عشوائياً.

### 2. الحسابات والصلاحيات والبيانات محلية — مانع للإطلاق الفعلي

`js/student-account.js` يحفظ حسابات الطلاب محلياً مع اشتقاق كلمة المرور بواسطة PBKDF2. أما جلسة الإدارة فتُحفظ في `sessionStorage` ويقرأها `js/access-guard.js`. هذه حماية واجهة وتجربة محلية؛ ليست مصادقة أو تفويضاً من خادم.

الحسابات والتقدم والمجتمع والحجوزات لا تتزامن بين الأجهزة. ملف SQL منفصل ولا يظهر ربط API تشغيلي في الواجهة. يلزم خادم يفرض الهوية والصلاحيات وحفظ البيانات قبل استخدام بيانات مستخدمين فعلية.

### 3. تغيير واستعادة كلمة المرور لا يغيران الحساب — فجوة وظيفية مؤكدة

الأثر: الطالب الذي أنشأ حساباً محلياً لا يملك من هاتين الشاشتين طريقة لتغيير كلمة مروره أو استعادتها. يلزم إكمال دورة الحسابات وربطها بالخادم، أو إبراز حدود المحاكاة بوضوح قبل إدخال البيانات.
