## المسارات والسلوك

- حُدّثت روابط HTML والصور والأنماط والسكربتات والنماذج والروابط التي يولّدها JavaScript، مع الاحتفاظ بمعاملات الاستعلام ومعرّفات الأقسام.
- يستخرج `workspace-shell.js` جذر التطبيق من عنوان السكربت، ويستخدم خريطة الصفحات لبناء الروابط والشعار. يبقى تحديد الدور والصفحة النشطة قائمًا على اسم الملف، وتُفحص وجهات روابط التنقل بعد تسوية عنوانها.
- تستخدم الاختبارات `tests/page-routes.js` لحلّ أسماء الصفحات في البنية الجديدة. تفحص تأكيدات الروابط الوجهات دون افتراض المسار القديم.
- لم تتغير مفاتيح التخزين أو مخططات البيانات أو ملفات CSS والأصول المرئية.
- جميع المسارات نسبية إلى المشروع، بما يسمح باستضافته لاحقًا داخل مجلد فرعي.
