## السلوك المنفذ

- يظهر محدد **My language** في لوحة الطالب والمسار، بكل لغات `language-catalog.js` وحالة توافرها. Python وJavaScript بحالة Ready؛ بقية اللغات Coming soon. تدعم تسمية المحدد حالة Preview أيضًا، لكن لا توجد لغة تُعلن هذه الحالة حاليًا.
- الاختيار مرتبط بصاحب الحساب. يشترك المحدد والتهيئة وإعدادات الملف في القيمة نفسها. تمنع واجهة الاختيار حفظ قيمة لحساب آخر إذا تغيّرت الهوية أثناء فتح الصفحة.
- التقدّم والمسودات ومحاولة تحديد المستوى منفصلة بحسب الطالب واللغة. تبقى مفاتيح Python القديمة كما هي؛ تضاف بادئة اللغة للغات الأخرى. لا تُنسخ سجلات Python إلى JavaScript، ولا تُحذف السجلات الأصلية عند التبديل أو ترحيل سجلات التبويب القديمة.
- يشترك الدرس والاختبار والمهمة في مخطط `curriculum-registry.js`، وتحتوي `curricula/python.js` و`curricula/javascript.js` على المنهجين المسجلين. بقيت معرفات Python كما هي، وتُستخدم ملفات دروسه وامتداده الحالية كمزوّدات بيانات دون نسخ محتواها إلى منهج آخر. بقي الاسم `pythonCurriculum` كواجهة توافق للصفحات القديمة، مع إتاحة المنهج الفعلي أيضًا باسم `activeCurriculum`.
- JavaScript يحتوي **3 مستويات و12 درسًا و3 اختبارات و6 مهام**. الدروس تتضمن شرحًا ومثالًا وسؤالًا وتمرينًا؛ لكل مستوى أربعة دروس واختبار من أربعة أسئلة ومهمتان. جميع مستوياته المنشورة مجانية. Python يبقى **6 مستويات و24 درسًا و12 مهمة**، مع شروطه السابقة لشهادة الأساسيات ومعاينة Premium المحلية للمستوى 6.
- تتبع لوحة الطالب والمسار والدروس والتمارين والمحرر وسياق المرشد والتقرير ومتطلبات الإنجاز اللغة الفعلية. يحتفظ تنزيل الحل بامتداد `.py` أو `.js` المناسب. يُظهر ملخص مستويات JavaScript العدد الفعلي بدل نص الستة مستويات القديم.
- لا يوجد بنك تحديد مستوى JavaScript حاليًا. تظهر صفحة صريحة تفيد بعدم توافره، دون إنشاء درجة أو تخطي مستويات. تبقى محاولة Python مستقلة. تحويل نتائج تحديد المستوى إلى نقطة بداية فعلية هو **المرحلة 2، ولم يُنفذ بعد**.
- اللغة غير الجاهزة تعرض صفحة توافر صريحة، وعلامة اهتمام محلية اختيارية **Notify me on this device**، وزر **Continue Python**. العلامة ليست اشتراك بريد أو إشعارًا خارجيًا.
- تستخدم الدورات المحلية معرف لغتها في ربط الدروس الأصلية، ويبدأ نموذج دورة جديدة باللغة المختارة عند توافرها. تتضمن اللقطة العامة المنشورة ودليل المواهب `languageId` عند إعادة النشر الصريحة، مع إبقاء المهارات كما كتبها الطالب. تغيير اللغة الخاص لا يعيد نشر ملفه تلقائيًا ولا يجعل مهاراته موثقة.

## تنفيذ JavaScript

ينفّذ `javascript-runner.js` البرنامج في Worker داخل iframe ذي sandbox دون `allow-same-origin`. يسمح CSP بتحميل كود Worker من Blob ويحظر اتصالات الشبكة. يقارن المضيف مصدر الرسالة ورمز تشغيل عشوائي، وتُزال نافذة التنفيذ عند الانتهاء أو الإيقاف أو تجاوز المهلة. يشرح توثيق MDN [وراثة CSP للـBlob workers](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy) و[عزل موارد sandbox عن الأصل](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/sandbox).

الحد خمس ثوانٍ، مع زر Stop وحد للإخراج 64 KB. يلتقط التنفيذ `console.log/info/warn/error`، ويوفر `input()` و`readLine()` لقراءة سطر نصي. هذا اصطلاح مساحة التعلم وليس دالة إدخال أصلية في JavaScript. المنهج الحالي تمهيدي ومتزامن؛ لا تدّعي الواجهة تنفيذ تطبيقات DOM أو برامج شبكة.

هذه اختبارات تعلم داخل المتصفح، **وليست تصحيحًا موثوقًا على الخادم**. الحلول المرجعية والتحقق ما زالا في ملفات العميل إلى حين المرحلة 4. المرشد ما زال إرشادات جاهزة؛ لا يوجد LLM أو `/api/mentor` أو مفتاح API أو خادم حسابات جديد.

## التحقق وحدوده

### جولة الاستكمال الأخيرة بالصلاحيات العادية

جرت **محاولة واحدة فقط** لتشغيل `tests/language-switch-browser.ps1` دون `require_escalated` أو تغيير الصلاحيات. انتهت قبل تشغيل أي تحقق لأن Chrome لم ينشئ `DevToolsActivePort`. لم تُجر محاولة أخرى أو تجاوز للمراجعة. لا تُصنّف هذه النتيجة كنجاح للفحص ولا كإخفاق لاختبار وظيفي؛ لم تبدأ التأكيدات أصلًا.

- نُفذت اختبارات Node/VM الثمانية: **139 تحققًا ناجحًا**، وصفر مجموعات مخفقة.
- نُفذ فحص صياغة **100 ملف JavaScript**: صفر أخطاء.
- نُفذ تدقيق **ثابت مستقل** لمراجع HTML المعلنة في 79 مسارًا: **158 مرجعًا، صفر مفقود**. لا يحل هذا محل تدقيق DOM أو فك الصور أو الاستثناءات في المتصفح.
- **لم تُعد المجموعات العشر الحالية بهذه الجولة** لأنها كلها تعتمد على Chrome/CDP، وليست اختبارات تعمل دون متصفح. وكذلك لم يُعد تدقيق المراجع الديناميكي للسبب نفسه. أسماء المجموعات وأسباب عدم التشغيل محفوظة في [نتيجة جولة الإغلاق](phase1-closure-results.json).
- بقي التحقق البصري من ملخص المستويات ومحدد My language على dashboard وlearning-path، باللغتين وعرضَي 1440 و390 بكسل، وفحص cross-tab/back/forward/focus/account-change في المتصفح، بحالة **pending manual verification**.
